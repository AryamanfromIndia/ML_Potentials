# ML_Potentials: Predicting Molecular Atomization Energies with Kernel Ridge Regression

Predicting the atomization energy of small organic molecules from their 3D geometry, using Coulomb matrix features and Laplacian kernel ridge regression (KRR) on a subset of the QM9 dataset.

## Overview

The project asks how well a simple, classical ML pipeline can learn a quantum-chemical property, and how that accuracy scales with training data.

- **Dataset:** [QM9](https://www.nature.com/articles/sdata201422) (about 130k small organic molecules with up to 9 heavy atoms of C, N, O, F), loaded through PyTorch Geometric.
- **Target:** atomization energy U0 (column 12 of `ds.y`), converted from eV to kcal/mol (x 23.0605).
- **Representation:** sorted, zero-padded Coulomb matrix (29 x 29, upper triangle, **435 features**).
- **Baseline:** atom counts per element (H, C, N, O, F, **5 features**), which contain no geometry information.
- **Model:** `sklearn.kernel_ridge.KernelRidge` with a Laplacian kernel, targets mean-centered, hyperparameters (`alpha`, `gamma`) tuned with 3-fold `GridSearchCV` on the training set only.

## Results

A random subset of 6,000 molecules is used: a fixed **1,000-molecule test set**, and a 5,000-molecule training pool from which the first N molecules are taken (so smaller training sets are subsets of larger ones). All values are test MAE in kcal/mol.

| N train | Coulomb matrix | Atom counts |
|---:|---:|---:|
| 100 | 33.6 | 28.7 |
| 250 | 22.6 | 21.9 |
| 500 | 18.0 | 20.7 |
| 1000 | 12.9 | 20.3 |
| 2000 | 10.1 | 19.8 |
| 5000 | **7.65** | 19.7 |

For reference, always predicting the training mean gives an MAE of 189.5 kcal/mol.

Key findings:

- **Power-law learning curve.** The Coulomb model's error falls roughly as N^-0.38 on log-log axes (fitted slope -0.38).
- **The baseline plateaus near 20 kcal/mol.** Atom counts cannot distinguish isomers, so more data does not help.
- **Crossover between N = 250 and 500.** With very little data, the 5-feature baseline is as good or better.
- **Error distribution at N = 5000:** median 5.9, RMSE 10.6, max 70.5 kcal/mol. About 74% of test molecules are within 10 kcal/mol and 44% within 5. Only about 9% are within 1 kcal/mol, so this does **not** reach chemical accuracy.
- **Errors are larger for small molecules** (MAE about 10.3 for 14 atoms or fewer, vs. about 6.6 for 19-22 atoms) and for the few fluorine-containing molecules (about 1% of the test set, so treat as suggestive).

### Requirements

- Python 3.10+ (developed on 3.13)
- `torch`, `torch_geometric`, `numpy`, `scikit-learn`, `matplotlib`, `jupyter`

```bash
pip install torch torch_geometric numpy scikit-learn matplotlib jupyter
```

### Run

```bash
jupyter notebook main.ipynb
```

Run the cells in order. The first run downloads QM9 into `data/QM9`. To skip feature building, you can load the cached features instead:

```python
import numpy as np
d = np.load("features.npz")
X, X_base, y, idx = d["X"], d["X_base"], d["y"], d["idx"]
```

### Runtime

The learning-curve loop re-tunes hyperparameters at each N with two 16-point grids and 3-fold CV. The full loop took a few minutes on a laptop (the largest N dominates).

## Method details

1. **Coulomb matrix.** For atoms i, j with nuclear charges Z and distance R: `M_ii = 0.5 * Z_i^2.4`, `M_ij = Z_i * Z_j / |R_i - R_j|`. Matrices are zero-padded to 29 atoms (the QM9 maximum), rows and columns are sorted by descending row norm to make the representation permutation-invariant, and the upper triangle is flattened.
2. **Split.** One fixed 1,000-molecule test set (`random_state=0`); training sets are the first N molecules of the remaining pool.
3. **Tuning.** `GridSearchCV` (3-fold, scored on negative MAE) over `alpha` and `gamma` for each model and each N. Grid ranges were widened until the test MAE stopped changing.
4. **Evaluation.** Test MAE after adding back the training-set mean.

## Limitations

- Only 6,000 of about 130k molecules are used, and results come from a **single random split** (no error bars).
- Coulomb matrices are a simple representation; modern descriptors (e.g. SOAP, FCHL) or neural networks would be expected to do considerably better.
- The reported hyperparameter optimum lies in a flat region, and some best values sit at grid boundaries without changing the test MAE.

## Possible extensions

- Repeat with several random splits and report mean and standard deviation.
- Compare kernels (Gaussian vs. Laplacian) and representations (bag of bonds, SOAP).
- Scale to more training data with approximate kernel methods or a neural network.
- Predict other QM9 targets (HOMO-LUMO gap, dipole moment).
